# Opt-in Eliscript Worker Client for FEmacs

Strictly opt-in asynchronous Eliscript worker client (`femacs-eliscript-worker.el`) built over the frozen JS worker runtime, value codec/stream, and Lisp service layer. Loading or building FEmacs does not spawn any JavaScript runtime until explicitly started by the user.

## Responsibilities

- **Install & runtime validation (`femacs-eliscript-resolve-install`)**: locates the selected runner (`bun` or `node`), validates an existing frozen worker package directory and client closure (`eliscript-value-codec.el`, `eliscript-value-stream.el`, `eliscript-worker.el`, `eliscript-service.el`), and fails cleanly with typed `missing-js-runtime` or `missing-worker-resource` errors without falling back to source bootstrap.
- **Per-session isolation & digest consistency (`femacs-eliscript-start`)**: binds each session's working directory cleanly per worker across initial launch, explicit restart, and automatic crash relaunch without mutating shared globals, and rejects conflicting `:project-manifest` and `:module-digest` inputs (`module-digest-conflict`).
- **Capability gate (`femacs-eliscript-require-capabilities`, `femacs-eliscript-probe-runtime-resolution`, `femacs-eliscript-runtime-resolution-probe`)**: checks advertised `ready` capabilities and runs live verification against relocated modules outside `node_modules` ancestors, recording `advertised`/`supported`/`honest` diagnostics and signaling `unsupported-capability` when a runner fails a declared capability.
- **Asynchronous requests & cancellation (`femacs-eliscript-call`, `femacs-eliscript-cancel`, `femacs-eliscript-await`, `femacs-eliscript-analyze-buffer`)**: returns explicit cancellable request handles instead of hiding uninterruptible synchronous wrappers; validates modification ticks (`stale-buffer`), applies buffer annotations inside `atomic-change-group`, and renders structured correlation metadata into `*Eliscript Analysis*`.
- **Single-run side-effect contract (`femacs-eliscript-call-side-effect`)**: forbids dual-run `:verify 'always`, never replays failed requests automatically, and reports `side-effect-completion-unknown` when timeout, disconnect, crash, or post-dispatch user cancellation leaves external state uncertain.
