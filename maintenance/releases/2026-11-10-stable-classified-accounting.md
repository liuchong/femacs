P463 implements the human-approved accounting policy while retaining all555
original files, all48 candidates and every original outcome. Frozen runtime
writers are unchanged. Closed raw stage results are assessed through the current
reader; new ledgers keep raw counts and separately report classified and blocking
cases. No classified case increases the original passing count or changes the
original failure/skip status, child exit or corpus-complete flag.

Rules bind the exact original input, candidate, reference selection, actual
run/completion/context and event/diagnostic signatures. Every rule has source
anchors and a reason. Required runtime/declared native/window capability failures,
incomplete execution, identity/registration changes and unexplained differences
remain blocking. Source explanations and optional-feature obligations also need
independent review; a matching hash alone does not prove their meaning.

The command accepts a completed build, explicit reference selection, reviewed
classification catalog, closed stage results and a fresh output directory. It
starts no editor/compiler and does not remove retained failure state. A partial
scope lists all remaining candidates. Full-stage accounting requires all48;
compatibility and Goal acceptance remain false pending actual full coverage and
required functionality evidence.
