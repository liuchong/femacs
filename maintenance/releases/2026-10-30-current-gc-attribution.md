# Current terminal collector and observer attribution

Fresh actual products exercise the existing observer and nonmoving young-cons
candidate. The selected data does not establish a speedup or justify changing
the default collector. All 306 measurement groups are busy/inconclusive; none
of 96 comparisons is eligible under the unchanged quiet-host policy.

## Products and execution

The previous observer product metadata pointed to missing executables. The
readiness attempt stopped before compiling or executing a workload; those
receipts were not relabelled as current products.

One immutable worktree-bound source export then builds terminal baseline plus
observer and collector plus observer, each in normal and checking configurations.
The collector's major and young controls use the exact same executable and dump.
Together with the installed 31.1 native-capable reference this gives seven
profiles and four newly built actual products. Candidate native compilation and
test hooks are disabled. This is not a clean committed-source export or a Cocoa
build. The source export retains the earlier committed process/thread code;
concurrent, unapproved process-wait edits are excluded rather than compiled while
being written. Product receipts retain the actual source and build bindings.

The build completes in 1,146.815 seconds, with 589,889,536 peak accounted bytes,
exit 0 and complete process-tree cleanup. Its hard deadline is 1,800 seconds.
No default terminal program or application package is published by this build.

The affected functional selection executes all eight observer and ten collector
IDs where applicable, in off/phases/survival/all observer modes. Forty discovery
processes and 352 test observations complete: 392 processes, zero failures or
skips. This includes forced actual minor collection, old-cons and noncons-owner
stores, weak tables, finalizers, explicit/cap full collection and bounded recorder
overflow. The owner exits 0 with complete cleanup in 288.879 seconds and
92,340,680 peak accounted bytes. Whole/case deadlines are 600/45 seconds. This
selection excludes language/native/fault-hook groups and is not full compatibility.

The selected performance run rotates 51 representation/observer controls for
two warmups and seven measured rounds: 459 workload processes (102 warmup,
357 measured), 63 separate startups (14 warmup, 49 measured), six workloads per
measured process and 2,142 samples. All executions pass, with zero collection
errors. Product/dump/full resources, fixtures and the separately bound driver
snapshot remain unchanged. State retirement completes. The owner exits 0 and
completely reaps its tree in 517.298 seconds, with 255,869,432 peak accounted
bytes and 900/45-second whole/case deadlines. Compilation/setup and startup are
separate from measured workload bodies. Normal and checking results remain
separate; checking is not presented as the release performance result.

## Selected observations, not promotion criteria

Normal terminal bytecode wall-time medians in milliseconds, seven samples per
cell. These descriptive readings preserve the busy-host limitation; differences
are not causal overhead or certified speedup estimates.

| Actual product/control | Churn, observer off | Retained, observer off | Churn, all | Retained, all |
| --- | ---: | ---: | ---: | ---: |
| Baseline + observer | 145.296 | 23.239 | 159.746 | 25.769 |
| Collector, major | 148.397 | 23.688 | 170.918 | 26.144 |
| Same collector, young | 206.511 | 35.827 | 231.618 | 36.565 |

The young/all/bytecode churn observations contain 231 actual Young and 84 Full
classification events across seven rounds. The retained workload contains
35 Young and 14 Full. This proves execution of the candidate's actual minor
path, not merely its requested mode. Recorded intervals have zero invalid
records, dropped records or observer errors in this selected run; sampled-cons
identity maps report no incompleteness. Capacity bounds remain 4,096 phase
records and 262,144 identity entries, not an unbounded recorder.

For normal bytecode churn, the baseline's 315 Full cycle-body intervals have
median 3.433 ms; static-root traversal plus recursive tracing is 2.926 ms and
cons sweep is 0.370 ms. In the young control, the 231 Young intervals have median
5.128 ms, static-root traversal 0.042 ms and cons sweep 0.868 ms. The directly
paired interval from input-blocked entry to static-root entry is 4.092 ms for
Young, versus 0.001 ms for baseline Full. The actual selected source places
collector preparation and remembered noncons-owner tracing before static roots.
This identifies that early interval as a concrete next investigation location;
it does not attribute every nanosecond to one function. These inclusive nested
intervals overlap and must not be added as exclusive costs or called hardware
stop-the-world/input-response latency.

The baseline/all bytecode churn's sampled live-cons age-bin medians are
1,040 / 4 / 2 / 4 / 18,573 and dead-cons medians are
0 / 109,656 / 1,981 / 0 / 0. Bins mean 0, 1, 2–3, 4–7 and 8+ sweep epochs.
They describe process-lifetime sampled conses at the case boundary, including
earlier cases/startup, not an isolated current-workload retention ratio or ages
of other object kinds. Allocation counters separately count conses, floats,
vector cells, symbols, string characters, intervals and strings; these are not
all byte counts. Heap inventory can be stale since the last collection.

No observer-off case has phase/age evidence; those controls are retained rather
than filled with inferred events. Complete raw rounds, pauses, memory samples,
allocation counters and phase arrays remain available. Maximum observed
load/core is 0.397, and all groups fail the existing quietness criterion.
