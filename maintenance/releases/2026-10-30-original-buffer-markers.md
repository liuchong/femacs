and `editfns-tests.el`, run unchanged from pinned stable commit
`a360712c9d272d950d8d8255ef74570f7e90b7d9` on the installed macOS reference
and current normal terminal/Cocoa. Existing per-file execution uses explicit
dumps, complete libraries and isolated manifest-verified test trees.

Each has 441 passes and one original graphical-mode skip, for **1,323 passes
and three skips**. Nine file processes exit 0 and complete, with no assertion
failure, timeout, protocol error or residual group. Status maps match across
all products. Shared skips keep the original aggregate **`passed=false`** and
protected-owner exit 1. Full inputs, programs/dumps/resources and trial App

original `deftest-*` macros. The 65 `overlay-autogenerated-test-*` definitions

registration and per-case completion, not source counts, determine coverage.

`display-graphic-p` guard is false in batch mode. It is not GUI acceptance.

and a buffer near 1,000 characters, with no added seed. The source describes
