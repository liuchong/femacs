# Repeated-message count formatting

P450 restores the missing percent in the existing intmax_t printf conversion.
Repeated messages now append a numeric suffix such as ` [2 times]`, allowing
subsequent repeats to parse and increment that count. The buffer size, count
type, duplicate parser, insertion order and undo/display behavior are unchanged.
This is one production source change, not a replacement formatting subsystem.
