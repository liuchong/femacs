## Decisions (WIP, PORTING.md P-26)

`emacs/lib/stdint.in.h` @ `fd7afced403`; port `femacs/lib/include/stdint.in.rs`.

This mirror is **deliberately partial** while only a few ported units need it: it carries
the integer-width section (`PTRDIFF_MIN`/`PTRDIFF_MAX`, `PTRDIFF_WIDTH`, the
`_GL_INTEGER_WIDTH` instantiation) plus the `int_fast64_t` alias that `character.h` names.
The unchecked boxes above are the rest of the header (the `_GL_*` type plumbing and the
`INTn_MAX`/`UINTn_MAX` families), which the first ported unit that needs them must add.

`PTRDIFF_MIN`/`PTRDIFF_MAX` come from the system `<stdint.h>` in C (gnulib defines them
only when the system lacks them); the frozen target's values are the 64-bit `isize`
limits, and `_GL_INTEGER_WIDTH` is a bit-for-bit transcription of `lib/limits.in.h`
(checked against the C compiler: `PTRDIFF_WIDTH == 64`).
