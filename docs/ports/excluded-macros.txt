# C macros that have no Rust counterpart yet, with the reason and the construct
# that replaces them.  One `<name>\t<kind>\t<reason>` per line; the inventory gate
# reports these separately instead of counting them as missing.  Mostly src/lisp.h;
# a mirror of another header appends its own rows here.
#
# kind=syntax   : the macro spells C syntax or an attribute; the port expresses
#                 it structurally.
# kind=config   : the macro selects a configuration branch that the port fixes.
# kind=debugger : the macro exists only so a debugger can see a value.
# kind=deferred : the macro is a control-flow construct whose Rust form is an
#                 open design decision (see PORTING.md P-22); it must be
#                 resolved before the files that use it are ported.
