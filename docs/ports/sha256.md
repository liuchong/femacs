## Decisions

- **`#if ! HAVE_OPENSSL_SHA256` is the live arm**; C 26-28's qualifier is dead text.
  `SWAP` is the sha1.c shape (`swap_bytes` live).
- **The message-schedule macros** `rol`, `S0`, `S1`, `SS0`, `SS1`, `M` and `R` are defined
  where C defines them (inside `sha256_process_block`, before the loop).  `M`'s comma
  operator becomes a block yielding the stored word, and its `tm` - C's loop-local, dead
  between expansions - is the expansion's own local (Rust hygiene).  `R`'s `A`..`H` are
  passed as the macro's first eight arguments (C's call sites pass them by name); its
  `t0`/`t1` are the macro's own locals, as in C; `while (0)`'s `0` is recorded in
  docs/ports/macro-body-notes.tsv.
- **`K(I)`** is the mirror's `K!` macro over `sha256_round_constants`, C's `static const`
  array with all 64 C values (transcribed, not recomputed).
- **C's state constants' `UL` suffixes** are the one token the port cannot spell; the rows
  are in docs/ports/macro-body-notes.tsv.
- **C's unsigned `+=`/`+` are `wrapping_add`**, `for (int t = 0; …)`/`for (int i = 0; …)`
  are `while` loops with their own counters, and `a = ctx->state[0] += a` is a block
  expression.
- **`sha256.h`'s mirror** carries the struct (`buflen` is C's `size_t` = `usize`), the two
  digest-size enums, the dead OpenSSL constants and the declarations.
