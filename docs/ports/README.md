# Per-file port ledgers

One file per ported C source: `docs/ports/NAME.md`, generated by

```sh
python3 tools/extract-abi.py emacs/src/NAME.c > docs/ports/NAME.md
```

The generated part is the checklist: every function, subr (`DEFUN`), macro, type,
extern and global of the reference file, as unchecked boxes. The porter ticks each
box as it is ported, and appends a `## Decisions` section recording:

- which `#if` branches are constant conditions and which are structural (`cfg`),
- every bitfield, union, function-pointer-with-context and flexible array member,
- the `alloca` strategy chosen per call site (`PORTING.md` §4.2),
- every deviation from the reference, with the reason,
- the call-relationship differences found (`D7`), or "none".

When a macro's Rust body legitimately cannot mention one of the tokens of the C body
(a deliberate re-shaping recorded in `PORTING.md`), the porter records the macro and those
tokens in `docs/ports/macro-body-notes.tsv`; the check still requires every other token,
so a mutation elsewhere in that macro still fails.  `docs/ports/excluded-macros.txt` is the
stronger form: the macro has no counterpart at all, with a reason.

Two more machine-checked records keep the "the port means the same thing" claim honest
(reviews A and D, 2026-10-02):

- `docs/ports/token-aliases.tsv` — token families the two languages spell differently
  (`memcpy`/`copy_nonoverlapping`, `va_arg`/`next_arg`).  A family is canonicalised in
  every body check *and* occurrence-checked: the port must use it at least as often as
  the C body does, so deleting a call cannot hide behind a note (`PORTING.md` P-44).
- `docs/ports/va-arg-types.tsv` — which object each `va_arg (ap, T)` /
  `next_arg::<T> ()` reads.  The multiset of reads must be identical, and a type that is
  not recorded is an error rather than a silent pass (`PORTING.md` P-45).

A file is done when:

1. every box is ticked,
2. `python3 tools/extract-abi.py --check emacs/src/NAME.c femacs/src/NAME.rs` prints `OK`,
3. two adversarial reviewers have attacked the diff and the applier has resolved
   every point they raised,
4. `docs/port-map.md` has been regenerated and the file's row is `ported`,
5. the signed commit `port(NAME): …` is pushed.
