# Per-file port ledgers

One file per ported C source: `docs/ports/NAME.md`, generated by

```sh
python3 tools/extract-abi.py emacs/src/NAME.c > docs/ports/NAME.md
```

The generated part is the checklist: every function, subr (`DEFUN`), macro, type,
extern and global of the reference file, as unchecked boxes. The porter ticks each
box as it is ported, and appends a `## Decisions` section recording:

- which `#if` branches are constant conditions and which are structural (`cfg`),
- every bitfield, union, function-pointer-with-context and flexible array member,
- the `alloca` strategy chosen per call site (`PORTING.md` §4.2),
- every deviation from the reference, with the reason,
- the call-relationship differences found (`D7`), or "none".

A file is done when:

1. every box is ticked,
2. `python3 tools/extract-abi.py --check emacs/src/NAME.c femacs/src/NAME.rs` prints `OK`,
3. two adversarial reviewers have attacked the diff and the applier has resolved
   every point they raised,
4. `docs/port-map.md` has been regenerated and the file's row is `ported`,
5. the signed commit `port(NAME): …` is pushed.
