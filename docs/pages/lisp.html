Install CLI or embed in Rust

Install and run the standalone binary

Prebuilt macOS & Linux binaries via Homebrew, npm, or shell installer (or build from source via Cargo); silent cold boot with background atomic .pdmp cache.

# Prebuilt standalone elisp for macOS & Linux
brew install liuchong/tap/elisp
npm install -g femacs
curl -fsSL https://femacs.com/install.sh | sh -s -- --only elisp

# Or build from source (all platforms)
cargo install elisp

elisp eval '(+ 20 22)'
elisp repl
elisp --concurrency=no-gil eval '(progn (require (quote std/json)) (std-json-stringify (list (cons "ok" t))))'

Embed lisp in your Rust application

Engine is Send in NoGil mode and supports safe host closures plus binary Value::Bytes.

// Cargo.toml: lisp = "0.0.1"
use lisp::prelude::*;

fn main() -> Result<(), Error> {
    let mut engine = Engine::init(EngineConfig::cold_stdlib())?;
    let val = engine.eval(r#"(progn (require 'std/json) (std-json-stringify '((ok . t))))"#)?;
    assert_eq!(val.as_str(), Some("[[\"ok\",true]]"));
    Ok(())
}

Tailor capabilities via Cargo features

Opt out of network/DB batteries or keep only pure-Rust process/RPC helpers.

# Full embedder runtime (default = ["vm", "std"])
lisp = "0.0.1"

# Lightweight VM sandbox without HTTP/TLS/redb
lisp = { version = "0.0.1", default-features = false, features = ["vm"] }

# Binary CLI without rustyline or std/* batteries
cargo install elisp --no-default-features --features repl-tty

Four cleanly layered crates

elisp ↗

[[bin]] standalone CLI, script/shebang runner, rustyline TTY REPL (elisp> ), init/pkg dependency manager, compiler, ERT test runner, and JSON-RPC worker. Defaults: ["repl-tty", "std"].

lisp ↗

[lib] high-level embeddable runtime exporting lisp::prelude::*, lisp::vm, and lisp::stdlib. Orthogonal vm, std, and pkg features plus default-features = false zero-VM process/RPC utilities.

lisp-std ↗

[lib] 100% pure-Rust (#![forbid(unsafe_code)], zero cc or C -sys crates) standard library batteries for HTTP/TLS, ACID KV & SQL, codecs, archives, crypto, time, FS/glob, and regex.

lisp-vm ↗

[lib] low-level headless VM, garbage collector, bytecode engine, HostExtFn host callbacks, .pdmp dump/restore, and opt-in isolate_vm per-isolate thread isolation.
