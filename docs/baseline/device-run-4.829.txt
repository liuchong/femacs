# Device readings for status 4.827-4.830 (2026-10-19)

Kept in the repository rather than in `/tmp` (R40): these are the readings the 4.829 verdict rests
on, and the harness that reproduces them is `tools/device-run.sh`.

Each run is a clean install (`adb uninstall` first - `install -r` is silently ignored when the
signature differs, status 4.823) and the numbers come from
`/data/data/org.femacs/files/probe.log`, which the process opens with `O_CREAT|O_APPEND` and closes
on every call, because logcat loses its tail when the process dies.

Probe tags: `FA` = `tools/add-fontset-probe.py` (the fontset macro, `fontset_add` and the caller's
loop), `CB` = `tools/add-chartab-probe.py` (the char-table range writers), `AL` =
`tools/add-alloc-probe.py` (`make_vector` and `garbage_collect`).  Every line carries `gettid()`
after the tag, because two threads append to the same file.
