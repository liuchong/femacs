# Units whose C-visible symbol table still differs from the reference object's.

# These are gnulib's "header-bodied" units: the .c file exists only to give the header's
# extern-inline functions a home, so the reference object exports them (`T _c_isalpha`,
# `T _stat_time_normalize`, the whole `_mpz_*` surface of mini-gmp-gnulib) while the port
# declares them in the mirror as `#[inline(always)]` functions, which emit no symbol at all.
# Closing one means giving the unit the `#[unsafe(no_mangle)]` definitions its C file emits.
#
# `lib/mini-gmp-gnulib` is not here: the C build yields only mini-gmp-gnulib.o
# (it includes mini-gmp.c), and the port puts those definitions in mini-gmp.rs, which
# `check-symbols.py`'s ALIASES table follows.
#
# The list is a ratchet: `tools/check-symbols.py --pending docs/baseline/symbol-pending.txt`
# fails on an entry that has become clean, so it can only shrink (status §3.30).
# `lib/regex` left the list in status 4.748, without merging anything: it is the *aggregate*
# translation unit (C 57-59 include regex_internal.c, regcomp.c and regexec.c), so its reference
# object exports all three files' symbols while the port keeps them in the three siblings
# (docs/ports/regex.md).  `check-symbols.py` now takes a stem list and compares the three
# siblings against that one object, which is why the gate demanded the entry's removal rather
# than a merge of the three into one - the empty list below is the ratchet's floor.
