# Units whose C-visible symbol table still differs from the reference object's.

# These are gnulib's "header-bodied" units: the .c file exists only to give the header's
# extern-inline functions a home, so the reference object exports them (`T _c_isalpha`,
# `T _stat_time_normalize`, the whole `_mpz_*` surface of mini-gmp-gnulib) while the port
# declares them in the mirror as `#[inline(always)]` functions, which emit no symbol at all.
