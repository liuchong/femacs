# The `lib/` sources the Android configuration's link needs, one per line.
#
# The frozen darwin list (`lib-link-sources.txt`) is the starting point: gnulib's `lib/` layer
# ships as `libgnu.a` in C, so it is in neither `frozen-build-sources*.txt`, and each target has
# to name the units it builds.  What differs for this target is recorded here rather than in the
# darwin list, because the darwin link does not need it:
#
#   * `lib/mini-gmp.c` is listed alongside its includer `lib/mini-gmp-gnulib.c`.  C compiles the
#     wrapper - `#include "mini-gmp.c"` under gnulib's allocator bindings - into one object
#     (`nxm -g build/emacs-ref/lib/mini-gmp-gnulib.o` prints 127 `T _mpz_*`), while the port keeps
#     the includer an empty unit and the definitions in `femacs/lib/mini-gmp.rs`
#     (tools/check-symbols.py's `ALIASES`, tools/check-link.py 22-23).  Without the includee the
#     Android link left all 59 `mpz_*` imports unresolved (status 4.708).
#
